# O программе

Проект представляет собой программу на языке C, которая читает текстовый файл, разбивает его на строки и выполняет три вида сортировки, записывая результаты в выходной файл или консоль:

1) Сортировка по возрастанию (лексикографически, слева направо, без учёта регистра и небуквенных символов).

2) Сортировка по убыванию (лексикографически справа налево, без учёта регистра и небуквенных символов).

3) Оригинальный порядок (восстановление исходного текста).

# Ocобенности программы

Программа написана на языке С и предназначена для операционной системы Windows. В других системах она будет некорректно работать.

# Установка и запуск 

1) Скачайте архив с проектом, распакуйте в произвольную директорию.
2) Если у вас не установлен компилятор языка С++ -- g++, установите его.
3) Скомпелируйте файл "onegin.cpp" и запустите его, указав в командной строке два аргумента через пробел: путь до файла с исходным текстом и путь до файла, в который записывать отсортированные строки. Если передать некорретное число аргументов в командную строку программа заврешит свою работу. Если аргументов командной строки не два — программа завершится с ошибкой EXIT_REASON_FILE_READING_ERROR.

# Функции в программе

## Работа с файлами

### char* read_from_file(FILE* name_file, size_t* str_number, off_t size_of_file_in)	
Читает весь файл в буфер, считает количество строк

### int print_strs_in_file(FILE* name_file, str_info_t* array_of_strs_info, size_t str_number, int (*compare_function)(void*, void*))	
Сортирует и печатает строки в файл

### void print_sorting_mode(FILE* name_file, int (*compare_function)(void*, void*))	
Печатает заголовок в зависимости от режима сортировки

### off_t size_of_file(const char* name_file)	
Возвращает размер файла в байтах

### str_info_t* create_array_of_structs(size_t str_number, char* buffer, off_t size_of_file_in)	
Создаёт массив структур, в которых первая перменная - указатель на строки, вторая - длина строки в байтах

### void open_file_and_clean(const char* name_file)
Открывает файл и очищает его содержимое


## Компараторы (функции сравнения)

### int compare_two_str_from_begin(void* first_argument, void* second_argument)
Сравнение строк лексикографически слева направо (без учёта регистра и не-букв)

### int compare_two_str_from_end(void* first_argument, void* second_argument)	
Сравнение строк лексикографически справа налево (без учёта регистра и не-букв)

### int compare_ptr_on_str_up(void* first_adress, void* second_adress)	
Сравнение по адресам строк (восстановление исходного порядка)

### void skip_not_letters_up(char* str, size_t* index_str, int* flag_end_string)	
Пропуск не-буквенных символов при движении вперёд

### int skip_not_letters_down(char* str, size_t* index_str, int* flag_end_string)	
Пропуск не-буквенных символов при движении назад


## Сортировка

### void quick_sort(void* left, void* right, size_t size, int (*comp)(void*, void*))	
Универсальная быстрая сортировка (qsort-подобная)

### void swap_numbers(char* value1, char* value2, size_t size)	
Обмен двух элементов произвольного размера

### size_t index_of_pivot(void* left, void* right, size_t size)	
Вычисление индекса опорного элемента

# Особенности реализации

1) Быстрая сортировка — работает с любым типом данных.
2) Сортировка без учёта регистра и с пропуском не-буквенных символов: пропускаются пробелы, знаки препинания и т.д
3) Сортировка в двух напралвениях: слева направо и справа налево.
4) Восстановление оригинального порядка — через сравнение  указателей на строки
5) Цветной вывод в консоль — макросы PINK и RESET для ANSI-цветов (в закомментированной функции).
